Section 01 // Executive Brief

Program Overview & Learning Outcomes

This curriculum delivers rigorous, practitioner-guided technical training designed specifically for college students and recent graduates. Rather than passive conceptual lectures, every module combines concept explanation, live code demonstration, guided hands-on laboratory exercises, and peer code reviews.

🎯 Target Educational Objectives:
By the completion of this program, learners are independently capable of designing, building, testing, and demonstrating working software artefacts adhering to modern industry best practices.

Core Evaluated Competencies:

01
Understand SDLC/STLC and testing fundamentals.
02
Write test scenarios, test cases and clear defect reports.
03
Automate browser workflows and validate APIs and databases.
04
Build a reusable automation framework with CI integration in the longer tracks.

Section 03 // Course Syllabus

Detailed Syllabi Across All Four Tracks

Complete, transparent breakdown of the topics, practical tools, and milestone projects covered across each duration tier.

Track 01 • Foundation Track

1 Week Track — 5 Working Days

Standard: 7.5 hrs • Extended Lab: 10 hrs • Earns: Technology Foundation Certificate

SDLC/STLC fundamentals, testing levels, test cases, bug reporting and introduction to automation.

Topic Progression & Lab Modules:

  • 1 Software development life cycle (SDLC) and testing life cycle (STLC)
  • 2 Testing levels, test types and defect life cycle
  • 3 Test scenarios, test cases and bug reports
  • 4 Manual testing of a sample web application
  • 5 Introduction to automation and Selenium; mini test exercise
Assessed Track Deliverable
Manual test suite and basic Selenium automation script on a live demo app
✓ Required for Technology Foundation Certificate
Track 02 • Applied Track

2 Weeks Track — 10 Working Days

Standard: 15 hrs • Extended Lab: 20 hrs • Earns: Applied Technology Certificate

Python for test automation, WebDriver control, XPath/CSS locators, waits and assertions.

Topic Progression & Lab Modules:

  • 1 All 1-week testing foundations
  • 2 Python basics for test automation
  • 3 WebDriver setup, browser control and page navigation
  • 4 Locators, XPath/CSS selectors and web element interactions
  • 5 Explicit/implicit waits, assertions, alerts and common browser actions
  • 6 Mini project: automate a basic login and checkout flow
Assessed Track Deliverable
End-to-end automated login, navigation and checkout test suite
✓ Required for Applied Technology Certificate
Track 03 • Professional Track

1 Month Track — 20 Working Days

Standard: 30 hrs • Extended Lab: 40 hrs • Earns: Professional Skills Certificate

Playwright, Pytest fixtures, Page Object Model, API testing with Postman, SQL data validation.

Topic Progression & Lab Modules:

  • 1 SDLC, STLC, test strategy and test documentation
  • 2 Manual testing: functional, regression, smoke and exploratory testing
  • 3 Python fundamentals for test automation
  • 4 Selenium WebDriver: setup, locators, waits and interactions
  • 5 Playwright introduction and modern browser automation concepts
  • 6 Pytest, fixtures, assertions and test organization
  • 7 Page Object Model (POM) and reusable automation design
  • 8 API testing with Postman; HTTP methods, status codes and assertions
  • 9 SQL basics for data validation; Git and GitHub workflows
  • 10 Mini capstone: maintainable web and API test suite
Assessed Track Deliverable
Maintainable Web & API Test Suite with Page Object Model and SQL data validation
✓ Required for Professional Skills Certificate
Track 04 • Advanced Industry Track

2 Months Track — 40 Working Days

Standard: 60 hrs • Extended Lab: 80 hrs • Earns: Industry Project Certificate

Full framework architecture, cross-browser Playwright, API automation, CI/CD pipelines and AI-assisted testing.

Topic Progression & Lab Modules:

  • 1 Testing foundations, SDLC/STLC, test planning and defect reporting
  • 2 Test design techniques, boundary values, equivalence classes and exploratory testing
  • 3 Python for automation: functions, collections, OOP and exception handling
  • 4 Selenium WebDriver: locators, waits, windows, frames and advanced interactions
  • 5 Pytest: fixtures, parametrization, markers and custom reporting
  • 6 Page Object Model, data-driven testing and framework architecture
  • 7 Playwright: browser contexts, selectors, waits and cross-browser execution
  • 8 API testing: Postman collections, environments and automated assertions
  • 9 API automation with Python requests/Pytest or REST Assured introduction
  • 10 SQL and database validation; test data setup and cleanup
  • 11 Git workflows, branching and collaborative test development
  • 12 CI/CD integration using Jenkins or GitHub Actions
  • 13 Test reporting, debugging, flaky test management and parallel execution
  • 14 AI-assisted test design and test generation with human review
  • 15 Capstone: end-to-end web and API automation framework with CI pipeline
Assessed Track Deliverable
Production-Grade Reusable Web & API Regression Framework with GitHub Actions CI/CD
✓ Required for Industry Project Certificate
